Sistema de Reservaciones

Sistema Interactivo de Reservas y Gestión de Citas (Vortex Web Studio) Desarrollo web front-end avanzado enfocado en la automatización de flujos de servicio y la experiencia de usuario (UX). Este proyecto destaca por un proceso de reserva estructurado en múltiples pasos (wizard), selección dinámica de horarios laborales según disponibilidad en tiempo real, y una robusta validación lógica de políticas de cancelación con un límite estricto de 24 horas de anticipación. Todo ello envuelto en una interfaz moderna, responsiva y orientada a la eficiencia operativa. Tecnologías: HTML5, CSS3, JavaScript (Vanilla), Font Awesome, Git y GitHub.
